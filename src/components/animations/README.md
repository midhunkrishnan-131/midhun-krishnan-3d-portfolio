# src/components/animations

Client wrappers: `SmoothScroll` (Lenis on `gsap.ticker`), `ScrollAnimations`
(per-section scrubbed timelines, typography reveals, parallax, magnetic buttons)
and `MotionProvider` (Framer Motion for UI micro-interactions only).

GSAP registration, the Lenis handle and shared eases live in `src/lib/animations`.
